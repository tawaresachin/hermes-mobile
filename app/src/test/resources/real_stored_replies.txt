**Author:** Lamhot Siagian | Version 1.0 | August 20, 2025

**Key Topics:**

2. **Evaluation Frameworks:**
   - RAGAS: Reference-free evaluation for faithfulness
   - ARES: Lightweight evaluators with minimal human annotation
   - Synthetic exam methods: Auto-generated domain-specific test items

3. **Practical Integration:** Java + Playwright + OpenAI API example showing:
   - DOM text extraction as "retrieval" step
   - LLM-as-oracle pattern for UI acceptance criteria
   - Structured JSON verdicts (pass/fail + evidence)

4. **Best Practices:**
   - Combine LLM judges with deterministic assertions
   - Use structured JSON output for reliable parsing
   - Avoid over-relying on sparse lexical metrics

5. **Case Study:** DevOps RAG assistant showed ~80% accuracy on single queries but ~90% failure rate on multi-document reasoning
